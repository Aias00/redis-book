# Redis 学习书交付计划

目标：完成原创中文 Redis 学习书，构建 EPUB 3 和可直接浏览的静态网站，提交至用户 GitHub 并启用 Pages。

## 设计

面向具备基本编程经验的读者，以 Redis 7.2 通用能力为实验基线。新版差异单独说明，不将扩展模块能力混同于基础 Redis。推荐 Markdown 单源、Pandoc EPUB 和 HTML；手写双份文档容易漂移，依赖在线 EPUB 阅读器则会限制移动端体验。因此在线阅读采用直接 HTML，EPUB 提供下载。

书名：《Redis 学习手册：从数据结构到生产实践》。章节按基础、可靠性、工程实践组织，包含可执行命令、失败边界、练习和答案。技术事实提供官方资料链接。正文使用简洁排版、章节目录与站内搜索，支持移动设备和深色模式。
